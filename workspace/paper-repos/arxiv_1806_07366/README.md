## What this paper does

Instead of stacking a fixed number of discrete layers, this paper parameterizes the *derivative*
of a hidden state with a neural network, `dh(t)/dt = f(h(t), t, θ)`, and computes the output by
handing that derivative to a black-box ODE solver. Gradients are computed via the **adjoint
sensitivity method**, which solves a second ODE backwards in time instead of backpropagating
through the solver's internal operations — giving **O(1) memory cost** regardless of how many
solver steps were taken. The same idea, applied to normalizing flows, gives **continuous
normalizing flows (CNFs)**, where the usually-expensive log-determinant-Jacobian term collapses
to a cheap trace via an "instantaneous change of variables" theorem. The paper also builds a
**continuous-time latent variable model** for irregularly-sampled time series.

This repo reproduces all three experiment families: MNIST classification (Table 1), CNF density
estimation (Figures 4-5), and the latent ODE time-series model (Table 2).

## Training

```bash
# MNIST classification (Table 1): resnet | rknet | odenet
python train_classification.py --variant odenet --config configs/config.yaml

# Continuous Normalizing Flow (Figures 4-5)
python train_cnf.py --target two_circles --mode density_matching
python train_cnf.py --target two_moons --mode maximum_likelihood

# Latent ODE time series (Table 2): 30/50/100 observed points
python train_latent_ode.py --num-observations 100

# Or via the generic dispatcher:
python train.py --experiment classification -- --variant odenet
```

All three scripts support `--config`, `--resume`, `--seed`, `--debug` (fast local smoke test),
and `--dry-run` (build everything, skip the actual training loop).

## Reproducibility notes

This repo was generated from a Scientific Intermediate Representation (SIR) with an overall
confidence of **0.70**. The following assumptions were made where the paper's text did not fully
specify an implementation detail — all are marked `# ASSUMED` in `configs/config.yaml` and at
their point of use in the code:

| Assumption | Confidence | Why |
|---|---|---|
| MNIST optimizer = Adam | 0.4 | Not stated for the classification experiment (only stated for CNF training) |
| MNIST batch size = 128 | 0.3 | Not stated anywhere in the parsed text |
| ODE solver = dopri5 (via `torchdiffeq`) | 0.6 | Paper's original experiments used implicit Adams (LSODE/VODE); dopri5 is the default in the authors' own released PyTorch library |
| Framework = PyTorch | 0.85 | Paper explicitly references a released PyTorch implementation (`github.com/rtqichen/torchdiffeq`) as the reference |
| Latent-ODE RNN cell = GRU | 0.4 | Only hidden-unit counts are given, not cell type |
| Spiral dataset observation noise std = 0.1 | — | Paper says noise is added but gives no numeric value |
| Downsample stem = two stride-2 3x3 convs | 0.4 | Exact stem architecture before the 6 residual/ODE blocks is unspecified |

**Known deviations from the original paper:**
- The original experiments used Autograd + `scipy.integrate` (LSODE/VODE via Fortran) + TensorFlow
  for the dynamics network; this repo uses PyTorch + `torchdiffeq` throughout (see assumption
  table above).
- The bi-directional spiral dataset used in Table 2 was never publicly released; this repo
  regenerates a statistically equivalent dataset from the paper's description (see
  `data/README_data.md`). Exact RMSE numbers may differ slightly as a result.
- A from-scratch implementation of the adjoint method (Appendix B/C) is included in
  `src/neural_ode/core/adjoint.py` for educational/faithfulness purposes, but the
  `torchdiffeq`-backed adaptive solver is the **recommended default** for actually reproducing
  results, since hand-rolled adjoint backprop is easy to get subtly wrong (see architecture plan
  risk assessment).

Full assumption/ambiguity details: `sir-registry/arxiv_1806_07366/sir.json`
(`implementation_assumptions` and `ambiguities` sections).
